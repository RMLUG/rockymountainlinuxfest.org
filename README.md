# RMLF + RMLUG

This code is for the rockymountainlinuxfest.org and it is also for the Rocky Mountain Linux User Group.

## Development

1. Clone the repo
2. Have python3 installed
3. Run local

```bash
python3 -m http.server 8000
```

The website should be visible on 127.0.0.1:8000 as long as this is running (so do it in a different tab).
